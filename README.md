# Projeto Spotify
 
Projeto acadêmico desenvolvido para a disciplina de **Programação para Internet**, com foco na estruturação, estilização e implementação de interfaces web inspiradas na plataforma Spotify.
 
## Tecnologias utilizadas
 
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Estrutura do projeto
 
```
Projeto_Spotify/
├── css/
│   └── estilo.css
├── imagens/
├── js/
├── index.html
└── README.md
```
 
## Como execução
 
Para executar o projeto localmente:
 
1. Clone o repositório ou faça o download dos arquivos.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para executar a aplicação em um servidor local.
 
## Objetivos
 
- Estruturação das páginas com HTML5 e estilização com CSS3.
- Utilizar o Bootstrap para apoiar a construção e a estilização das interfaces.
- Desenvolver uma página de login integrada à estrutura existente do projeto.
- Praticar a organização de arquivos e o desenvolvimento de interfaces web.
